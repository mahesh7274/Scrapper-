# Mobile Scraper Research Browser 2.0

Native Android Studio project for e-commerce scraper research.

V2 includes:
Browser/session, cookies, DOM discovery, product discovery, pagination discovery,
resource + Fetch/XHR capture, console capture, local/session storage,
Python/cURL request templates, JSON/HAR-like export, AI research pack.

It observes traffic available to its own WebView and page JavaScript.
It does not bypass TLS pinning, CAPTCHA, authentication controls, or another app's sandbox.
